## 1. Backend Service (`apna-parking-backend/`)
*Built with Python 3.13, Flask REST API, SQLAlchemy ORM, MySQL, and Razorpay SDK.*

| File Name | What It Has & Why It Is Needed (One-Line Summary) |
|---|---|
| [`app.py`](file:///c:/Users/Pragati%20Trivedi/OneDrive/Desktop/Internship/Apna_Parking/apna-parking-backend/app.py) | **Has:** The Flask application factory, database connection initialization, CORS setup, and user authentication routes (`/signup`, `/login`, `/profile`, `/logout`).<br>**Why Needed:** Acts as the central backend entry point that boots the server, secures API access with JWT tokens, and registers all feature blueprints. |
| [`models.py`](file:///c:/Users/Pragati%20Trivedi/OneDrive/Desktop/Internship/Apna_Parking/apna-parking-backend/models.py) | **Has:** SQLAlchemy ORM model class definitions for `User`, `Location`, `ParkingSpace`, `Booking`, `Payment`, `Vehicle`, and `ContactInquiry`.<br>**Why Needed:** Maps database tables to Python objects and provides JSON serialization methods (`to_dict()`, `to_frontend_dict()`) matching the frontend's visual contracts. |
| [`parking_spots.py`](file:///c:/Users/Pragati%20Trivedi/OneDrive/Desktop/Internship/Apna_Parking/apna-parking-backend/parking_spots.py) | **Has:** REST API route handlers for `/api/parking-spots`, `/api/parking-spots/nearby`, `/api/parking-spots/<id>`, `/api/stats`, and `/api/contact`.<br>**Why Needed:** Powers the live GPS radar search using the Haversine formula, serves multi-floor parking layouts, and delivers real-time platform statistics to the web app. |
| [`payments.py`](file:///c:/Users/Pragati%20Trivedi/OneDrive/Desktop/Internship/Apna_Parking/apna-parking-backend/payments.py) | **Has:** API endpoints for creating bookings (`/bookings`), generating Razorpay orders (`/payments/create`), verifying HMAC signatures (`/payments/verify`), and managing extensions/cancellations.<br>**Why Needed:** Orchestrates the core transaction lifecycle, prevents double bookings with atomic collision checks, and cryptographically confirms bank payments before issuing passes. |
| [`razorpay_client.py`](file:///c:/Users/Pragati%20Trivedi/OneDrive/Desktop/Internship/Apna_Parking/apna-parking-backend/razorpay_client.py) | **Has:** A singleton helper function `get_razorpay_client()` that reads credentials from environment variables and initializes the official Razorpay SDK client.<br>**Why Needed:** Centralizes payment gateway credential loading and provides a sanitized, reusable Razorpay API instance across the backend. |
| [`extensions.py`](file:///c:/Users/Pragati%20Trivedi/OneDrive/Desktop/Internship/Apna_Parking/apna-parking-backend/extensions.py) | **Has:** Global instances of SQLAlchemy (`db`), Flask-JWT-Extended (`jwt`), and Flask-Limiter (`limiter`).<br>**Why Needed:** Prevents circular import errors in Flask by separating extension initialization from the main application instance. |
| [`seed_data.py`](file:///c:/Users/Pragati%20Trivedi/OneDrive/Desktop/Internship/Apna_Parking/apna-parking-backend/seed_data.py) | **Has:** Database migration logic (`sync_database_schema()`) and seed records for 6 realistic multi-floor Pune parking facilities with hundreds of slots.<br>**Why Needed:** Automatically synchronizes MySQL table schemas without data loss and populates initial demo data for testing and demonstrations. |
| [`test_app.py`](file:///c:/Users/Pragati%20Trivedi/OneDrive/Desktop/Internship/Apna_Parking/apna-parking-backend/test_app.py) | **Has:** A comprehensive test suite containing 25 automated unit and integration tests executed with pytest.<br>**Why Needed:** Guarantees backend stability by verifying user authentication, spot filtering, payment creation, signature verification, and booking cancellations on every code update. |
| [`requirements.txt`](file:///c:/Users/Pragati%20Trivedi/OneDrive/Desktop/Internship/Apna_Parking/apna-parking-backend/requirements.txt) | **Has:** A pinned list of all Python library dependencies (`Flask`, `Flask-Cors`, `Flask-JWT-Extended`, `SQLAlchemy`, `PyMySQL`, `razorpay`, `email-validator`, `pytest`).<br>**Why Needed:** Ensures any developer or deployment server can replicate the exact Python virtual environment with a single `pip install -r requirements.txt` command. |
| [`.env`](file:///c:/Users/Pragati%20Trivedi/OneDrive/Desktop/Internship/Apna_Parking/apna-parking-backend/.env) | **Has:** Secret configuration values including MySQL `DATABASE_URL`, `JWT_SECRET_KEY`, and Razorpay `RAZORPAY_KEY_ID` / `RAZORPAY_KEY_SECRET`.<br>**Why Needed:** Keeps sensitive database passwords and payment API private keys secure and externalized from source control. |
